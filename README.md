# مخزني

تطبيق Flutter لإدارة المتجر على Android وiOS، يعمل محلياً دون اتصال بقاعدة SQLite.

## المنجز في البداية
- واجهة عربية واتجاه RTL مع إعداد تبديل اللغة العربية/الإنجليزية.
- قاعدة SQLite محلية لبيانات المنتجات والإعدادات والمبيعات والمشتريات.
- إضافة المنتجات وعرضها.
- صفحة تقارير تتضمن تصدير قائمة المخزون إلى Excel، تنزيل نموذج المنتجات، واستيراد ملف `.xlsx`.

## قالب Excel
ورقة العمل الأولى تحتوي أعمدة بالترتيب التالي: `name`, `barcode`, `price`, `quantity`. استخدم أرقاماً صالحة للسعر والكمية، واحفظ بصيغة `.xlsx`. الباركود اختياري؛ إذا تكرر باركود المنتج فسيتم تحديث السجل الموجود.

## التشغيل
```sh
flutter pub get
flutter run
```
