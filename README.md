# مخزني

تطبيق Flutter يعمل على Android وiOS لإدارة المخزون ونقاط البيع والمشتريات والعمل دون اتصال.

## الميزات المخطط لها

- تسجيل المنتجات بأسمائها وأكوادها وأكواد الباركود
- مسح الباركود لإضافة المنتجات للمخزون أو البيع
- نقاط بيع مع السلة والحساب والخصم وإتمام الفاتورة
- حركة مخزون وإشعار الحد الأدنى
- فواتير المشتريات والموردين
- عملاء ومستحقات مبسطة
- تقارير المبيعات والمخزون والمشتريات
- قاعدة SQLite محلية مع تصدير نسخ احتياطي قابل للتنفيذ لاحقًا

## التشغيل

```sh
flutter pub get
flutter run
```

اللغة: العربية، العملة: الريال اليمني، اتجاه واجهة من اليمين إلى اليسار.
